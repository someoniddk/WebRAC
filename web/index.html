Settings

Descriptions appear below each setting. Saved in this browser and applied when you press Play.

Graphics

Choose a preset for several graphics options at once. Custom lets you adjust them separately.

Smooths jagged edges. Higher levels use more GPU power; Original uses the game's normal rendering.

Sets how far level details remain visible. Farther settings can cost more performance.

Changes how textures look when viewed at an angle or from a distance.

Original keeps the game's HUD sampling. Sharp pixels keeps HUD edges crisp at larger resolutions.

Display

Chooses the game picture's shape. Fill uses the whole view and may stretch the picture.

Sets the game's render height. Window follows the browser view; larger sizes need more GPU power.

Opens the game in browser fullscreen when you press Play. The browser may require a user click.

Performance

Caps how often the game renders. Off leaves the limit to the browser and display refresh rate.

Skips level objects hidden behind solid geometry. Turn it off if an object disappears incorrectly.

Asks the browser for a lower-latency presentation mode when supported. The display still sets the top frame rate.

Controls

Enables mouse camera input and map controls. Hold right mouse to look; drag the map with left mouse and use the wheel to zoom.

Scales mouse camera movement. This does not change map zoom speed.

Game
